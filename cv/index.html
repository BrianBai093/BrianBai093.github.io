Research Experience

  • 2026 - present

    Hangzhou, China

    Research Assistant
    Zhejiang Lab
    Advisor: Jiaxi Yang, Research Scientist, Zhejiang Lab
    • Project: Feedback Learning for EHR SQL Repair: SFT vs. GRPO; manuscript in preparation.
    • Conducted a pre-registered study comparing SFT and GRPO on how diagnostic feedback shapes learning for EHR SQL repair, fine-tuning Qwen3.5-9B on MIMIC-IV EHR questions under four nested feedback levels, from a bare failure signal to repair hints.
    • Trained 12 QLoRA adapters (4 feedback conditions x 3 seeds, 1,200 samples) and evaluated semantic repair success across 13 model groups and 10,400 records, using paired comparisons with task-clustered confidence intervals, permutation tests, and Holm correction.
    • Found no stable incremental benefit from richer feedback under SFT: matched gains of +1.0 to +2.0 percentage points did not meet the pre-registered significance bar, a carefully bounded null result.
    • Built a target-free GRPO pipeline with a custom binary execution reward and observed a non-monotonic feedback effect, with the intermediate L2 level reaching +10.0 points (95% CI [+4.0, +16.5], exploratory Holm-adjusted p = 0.0228), pending multi-seed confirmation.
    • Ran all 12 adapters on a single 24 GB GPU under a strict no-leakage protocol, with reward verification isolated in a read-only database worker that never returns gold answers or verifier diagnostics to the model.

    • Designed and implemented DeepAudit, an agentic claim-level reproducibility auditing system that maps ML paper claims to executable repository tasks, metric contracts, runtime artifacts, and structured verdicts.
