This repository packages E2B's developer documentation into a structured set of Codex skills. It includes a master routing skill and specialized skills for sandbox runtime management, command execution, filesystem operations, code-interpreter workflows, MCP integration, template building, CLI operations, agent integrations, administration, and troubleshooting.

## Why It Matters

The project is less about a single model result and more about making agent tooling operational: it turns broad platform documentation into scoped, triggerable workflows that an assistant can load progressively instead of reading every document at once.

## Technical Scope

- Skill design for agent routing and progressive context loading.
- Separate domain skills for E2B sandbox lifecycle, filesystem operations, command execution, MCP integration, and troubleshooting.
- Reusable structure with `SKILL.md`, references, and UI metadata for each skill.
- Directly aligned with my interest in agent systems, tool use, and reliable execution environments.
